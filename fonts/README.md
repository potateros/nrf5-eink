# Fonts

From the [TRMNL framework](https://github.com/usetrmnl/trmnl-framework) (`public/fonts`), SIL Open Font License 1.1: `OFL.txt` (TRMNL bundle + Inter) and `OFL-classic.txt` (NicoClean, © 2021 Emily Huo).

| File | Use | Native size |
| --- | --- | --- |
| `TRMNL12-Bold.ttf` | small labels (hours, chart axis) | 12 px |
| `TRMNL16-Bold.ttf` | body lines | 16 px |
| `TRMNL21-Bold.ttf` | headings, condition, temperatures | 21 px |
| `TRMNL12-Regular.ttf` / `TRMNL16-Regular.ttf` / `TRMNL21-Regular.ttf` | lighter body text and labels (`regular()`); TRMNL16 Regular also at 14 px for sub-lines | 12 / 16 / 21 px |
| `NicoClean-Regular.ttf` | body text and labels (`medium()`); even weight between TRMNL Regular and Bold | 16 px (clean at 14-15) |
| `Inter.ttf` (variable, set to Bold) | big temperature / headline | any, ≥ 26 px |

The TRMNL fonts are pixel fonts: they only render cleanly at their native size (rendered with anti-aliasing off).
