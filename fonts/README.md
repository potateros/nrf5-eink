# Fonts

From the [TRMNL framework](https://github.com/usetrmnl/trmnl-framework) (`public/fonts`), SIL Open Font License 1.1 (see `OFL.txt`).

| File | Use | Native size |
| --- | --- | --- |
| `TRMNL12-Bold.ttf` | small labels (hours, chart axis) | 12 px |
| `TRMNL16-Bold.ttf` | body lines | 16 px |
| `TRMNL21-Bold.ttf` | headings, condition, temperatures | 21 px |
| `TRMNL16-Regular.ttf` | spare | 16 px |
| `Inter.ttf` (variable, set to Bold) | big temperature / headline | any, ≥ 26 px |

The TRMNL fonts are pixel fonts: they only render cleanly at their native size (rendered with anti-aliasing off).
