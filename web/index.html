    What this is

    A small control page for the 4.2″ NRF_EPD_5E5D tag. It speaks the tag's Bluetooth protocol from this browser: send pictures, store them in the firmware's 15 slots, start the slot carousel, and switch the built-in calendar and clock. It replaces the vendor's web tool, which loads from someone else's server and posts your device id (sid) to a paid rendering service.

    Private by construction. Everything is served from this Mac at localhost:8742. The page has a Content-Security-Policy that forbids any network request except to this local server, so images never leave the machine. The only outside traffic is the optional Dashboard layout render, which fetches weather (Open-Meteo, NEA), your calendar and, for note/auto, a haiku from OpenRouter, exactly as the scheduled push already does.

    Before you start

    1. Use Chrome or Edge on the Mac. Safari and Firefox have no Web Bluetooth. A phone can't use this page: phones only allow Bluetooth on https or on their own localhost.
    2. Allow Bluetooth for Chrome once: System Settings → Privacy & Security → Bluetooth.
    3. Pause the scheduled push. The tag accepts one connection at a time, and a push every 30 min would also overwrite what you show. In a terminal: hq hold eink-dashboard-1. When you're done: hq resume eink-dashboard-1.
    4. Start the page: in the hq TUI select EINK-TOOL and press R, or run uv run eink web in the repo. Either opens Chrome. Started from hq, it stops by itself 10 min after you close the tab.

    Sending a picture

    1. Connect, then pick NRF_EPD_5E5D in Chrome's chooser. The tag advertises intermittently, so it can take up to ~45 s to appear.
    2. Choose an image, or a Dashboard layout and Render.
    3. Tune it. Dither: None suits text and dashboards; Floyd–Steinberg or Atkinson suit photos. Black only drops red. Threshold (black only, no dither) sets how dark a pixel must be to print black. The preview is exactly what the panel will draw.
    4. Choose where it's saved: the scratch slot (14) for a one-off, or a slot to keep it.
    5. Send to panel. Upload takes ~10 s, then the panel needs ~30 s to refresh. Keep the tab open and connected until the bar finishes. Disconnecting mid-refresh freezes the panel black, inverted or blank (just send again).

    Calendar at midnight (on by default) is the same safety net the scheduled push uses: if nothing else is sent, the firmware replaces your picture with its own calendar at local midnight. Turn it off for a picture that should stay up for days.

    Slots

    The firmware keeps 15 pictures in its flash. Every upload, from this page or from the scheduled push, is saved into the current slot (shown with a ring), so this page sends one-offs to the scratch slot 14 and leaves 0–13 for pictures you keep.

    • Store: pick a slot under Save to, then send. Storing also displays it.
    • Show: click a slot, then Show slot. It redraws from flash, with no upload (~30 s refresh).
    • Delete: frees the slot. It can't be undone.

    Protecting kept slots. Storing in or showing slot n makes it the current slot, and the next upload, including the scheduled push, would be saved there. So after either, this page points the target back at scratch slot 14 and checks it took (the log says Slot n protected). If the log shows an error instead, keep the scheduled push on hold while that picture matters.

    Note: the scheduled push still redraws the panel every 30 min. A shown or kept picture stays on screen only while the job is on hold; afterwards it stays safe in its slot.

    Carousel

    Start carousel makes the panel cycle through every stored slot every N minutes on its own, with no Mac and no Bluetooth after the command. It stops on the next send, Calendar, Clock or scheduled push. Each change is a full refresh, so a short interval costs battery: an hour or more is kind to it. Delete slots you don't want in the rotation. Untested so far: whether it survives the midnight redraw or switching the tag off.

    Good uses: an away mode (fill slots with photos or posters, hold the job, start a slow carousel), or fixed screens such as a guest Wi-Fi QR or "in a meeting".

    Panel modes

    • Calendar: syncs the tag's clock and draws the firmware's month calendar; redraws at midnight.
    • Clock: the firmware's clock, redrawn every minute. The seller warns against leaving a three-colour panel on clock for long (burn-in).
    • Clear screen: a full white wipe that fixes ghosting. The tag is busy for ~25 s afterwards.

    Safety rules built in

    • A red plane is always sent (all white if unused), or old red shows through.
    • Buttons lock for 30 s after anything that refreshes the panel, so it isn't interrupted.
    • Config writes change only the display-mode byte, from a fresh read.
    • Not included on purpose: setting pins or driver (overwrites model 0x16), config erase, deep sleep (no wake pin), firmware updates, and the vendor's paid remote templates.

    If something goes wrong

    • Chooser shows nothing: another program is connected (the scheduled push or the vendor tool), or the tag is between adverts. Hold the job, close other tools, try again.
    • Panel half-drawn, black or inverted: the refresh was cut off. Send again and wait for the bar.
    • Stuck ghosting: Clear screen, wait, then send.
